# AI-Enabled Smart Traffic Density Prediction and Monitoring System Using SUMO, Python, YOLOv8 and Streamlit

## Overview
An AI-powered traffic monitoring system that detects vehicles using YOLOv8, simulates traffic scenarios with SUMO, and visualizes traffic density through a Streamlit dashboard.

## Technologies Used
- Python
- YOLOv8
- SUMO
- Streamlit
- OpenCV
- Pandas
- NumPy

## Features
- Real-time vehicle detection
- Traffic density monitoring
- Traffic simulation using SUMO
- Interactive Streamlit dashboard
- Vehicle counting and data analysis

- data/
- model/
- simulation/
- app.py
- train_model.py
- yolo_detection.py
